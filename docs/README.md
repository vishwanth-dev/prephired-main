## Documentation Conventions

When creating new documentation, please follow these guidelines:

1. **Date-based Organization**: Save all documentation under `docs/{YYYY_MM_DD}/`
2. **Category Folders**: Use appropriate category folders:
   - `guides/` - How-to guides, tutorials, and reference materials
   - `specs/` - Requirements, specifications, and feature definitions
   - `tasks/` - Task lists, TODO tracking, release checklists
   - `design/` - Architecture diagrams, design documents, technical plans

3. **File Naming**: Use descriptive kebab-case names (e.g., `claude-subagent-system-guide.md`)
4. **Markdown Format**: All documentation should be in Markdown format
5. **Updates**: Update this README when adding new significant documentation

## Contributing

When adding new documentation:

1. Create the appropriate directory structure if it doesn't exist
2. Place your document in the correct category folder
3. Update this README with a link to your new document
4. Follow the existing formatting and style conventions
